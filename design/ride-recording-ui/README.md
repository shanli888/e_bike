# 骑行记录功能 · UI 设计原型

## 定调说明

**受众**：电助力自行车码表用户（含无助力器的普通骑行者）。
**风格方向**：工业实用（Industrial / utilitarian）——仪表盘信息密度、等宽数码管、发丝边框、严格的状态色语义。与真机现有视觉一脉相承，不做风格跃迁。
**字体**：展示字沿用项目自带的 DSEG7 七段数码管（`SEGClassic.ttf`），是产品的核心记忆点；标签用等宽字体，正文用中文黑体。
**配色**：深空蓝黑底（`#0a0e1c`）+ 橙色主强调（`#ffb020`），绿=GPS/正常、蓝=蓝牙/副数据、红=录制/告警，60/30/10 分配。记录功能仅新增"录制红"与"轨迹绿"两个语义色。
**记忆点**：真机同款指针速度表盘 + "分水岭"切换——未连接助力器时，助力控制区整块让位给"开始骑行"主行动点。

## 动效规格

- **入场序列**：三栏（选择器 / 手机 / 说明）错峰 90ms，640ms `cubic-bezier(.16,1,.3,1)` 上浮淡入，纯 CSS 驱动。
- **录制脉冲**：录制点 1.6s 呼吸（`recPulse`），是全稿唯一持续动效，强调"正在记录"。
- **降级**：`prefers-reduced-motion: reduce` 下由 `base.css` 统一关闭全部动效。

## 自检结果

- **反 AI 味清单**：0 项未修复命中（展示字为专用数码管而非 Inter 系；无白底紫渐变；非居中标题+三卡套路；图标均有信息含义；文案无空话）。
- **可访问性**：正文对比度 ≥ 4.5:1；交互控件 ≥ 44px 触摸目标；`:focus-visible` 可见描边；语义化标签 + 隐藏 SVG `aria-hidden`。
- **布局**：390×844 手机视口逐屏截图核验，7 屏全部无溢出、无重叠、无裁切。
- **状态覆盖**：默认态（01/05）、连接态（02）、进行态（03/07）、结果态（04）、详情态（06）均有呈现。

## 已知取舍

- 导航屏为"路书跟随"的轻量实现（自绘轨迹 + 进度 + 偏航 + 关键点），不含实时算路与在线瓦片，符合离线定位。
- 原型为静态数据展示，按钮仅为视觉演示（左侧列表与 `[data-go]` 跳转可用），不含真实记录逻辑。
